Import

Upload the game’s own files: KEYBIND.DAT says which key each hotbar slot is bound to, HOTBAR.DAT says which ability is on it. Both are needed; neither is useful alone.

These files are read in your browser. Nothing is uploaded unless you sign in with Discord and press Save to account.
